# Cartella Programmi

Organizza qui i programmi scaricati dai siti degli atenei.

## Struttura

Programmi/
    Nome_Materia/
        Classe_Laurea/
            NomeAteneo_Docente.pdf

## Esempio

Programmi/
    Chimica_Organica/
        L-13/
            UniMilano_Rossi.pdf
            UniRoma_Bianchi.pdf
        L-27/
            UniPadova_Neri.pdf

## Come aggiungere programmi

1. Naviga sul sito dell'ateneo
2. Trova il programma del corso
3. Se PDF: scaricalo direttamente
4. Se pagina web: Stampa > Salva come PDF
5. Salvalo nella cartella corretta
6. Nomina il file: Ateneo_Docente.pdf
